# R6 微信群战绩查询机器人

使用 Node.js + TypeScript 开发，目标是在 Windows 本地运行。

## 当前状态

- 使用模拟群消息，尚未连接微信。
- 仅处理 mentionedBot 为 true 且符合查询格式的消息。
- 查询格式：@机器人 查询 玩家 ID
- 项目支持虚构战绩演示和 R6Data 真实查询，两种方式目前都通过模拟群消息运行。
- 回复明确标注“演示战绩｜虚构数据，非实时”。
- 消息适配层和战绩数据源可独立替换。

## 本地命令

```powershell
npm test
npm run typecheck
npm run build
npm start
```

修改源码后，需要重新 build，npm start 才会运行最新代码。

## 接入前待核实

- 个人微信接入方案的可用性、版本兼容性及账号风险。
- 是否能够准确识别提及机器人的消息元数据。
- R6 数据源的访问权限、授权方式、限流和数据更新时间。

## 查询真实战绩

在项目根目录创建 `.env`，填写自己的 R6Data API 密钥：

```dotenv
R6DATA_API_KEY=你的密钥
```

在项目根目录运行：

```powershell
npm run query -- "LabmemNo.04"
```

命令通过模拟群消息查询 PC 玩家战绩，输出历史总 K/D、历史总胜率、
当前赛季排位 K/D、胜率、段位，以及排位 3.0 历史最高记录。

历史汇总和最高记录取决于 R6Data 返回的数据覆盖范围。
换电脑后，安装项目依赖并重新配置 `.env` 即可运行终端查询。
段位对照表已随项目提交。
