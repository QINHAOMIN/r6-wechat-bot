# R6 微信群战绩查询机器人

使用 Node.js + TypeScript 开发，目标是在 Windows 本地运行。

## 当前状态

- 使用模拟群消息，尚未连接微信。
- 仅处理 mentionedBot 为 true 且符合查询格式的消息。
- 查询格式：@机器人 查询 玩家 ID
- 返回固定的虚构演示战绩，尚未接入真实战绩数据源。
- 回复明确标注“演示战绩｜虚构数据，非实时”。
- 消息适配层和战绩数据源可独立替换。

## 本地命令

```powershell
npm test
npm run typecheck
npm run build
npm start
```

修改源码后，需要重新 build，npm start 才会运行最新代码。

## 接入前待核实

- 个人微信接入方案的可用性、版本兼容性及账号风险。
- 是否能够准确识别提及机器人的消息元数据。
- R6 数据源的访问权限、授权方式、限流和数据更新时间。
